Step 1 — Create a Docker Hub repository
Go to Docker Hub and log in.
Then:
1.	Click Repositories 
2.	Click Create repository 
3.	Repository name:
ai-olms
4.	Choose Public (unless your faculty requires private) 
5.	Click Create 
Your repository will look like:
YOUR_DOCKERHUB_USERNAME/ai-olms
For example, if your username is joshitha123:
joshitha123/ai-olms
________________________________________
Step 2 — Login from Git Bash
Open Git Bash and run:
docker login
Docker will ask for your Docker Hub username and password/token.
After successful login, you should get:
Login Succeeded
If Docker asks for a password, use your Docker Hub password or an access token if your account requires token-based authentication.
________________________________________
Step 3 — Check your existing image
You already created:
docker build -t ai-olms:latest .
Check it:
docker images
You should have:
REPOSITORY    TAG       IMAGE ID
ai-olms       latest    xxxxxxxxx
________________________________________
Step 4 — Tag the image for Docker Hub
This is the important step.
Suppose your Docker Hub username is:
joshitha123
Run:
docker tag ai-olms:latest joshitha123/ai-olms:latest
Replace joshitha123 with your actual Docker Hub username.
Now check:
docker images
You should see both:
ai-olms                  latest
joshitha123/ai-olms      latest
They refer to the same image.
________________________________________
Step 5 — Push to Docker Hub
Run:
docker push joshitha123/ai-olms:latest
Again, replace joshitha123 with your username.
You'll see Docker uploading the image layers.
At the end, you should get something similar to:
latest: digest: sha256:xxxxxxxx...
That means the image has been pushed successfully.
________________________________________
Step 6 — Verify on Docker Hub
Open your Docker Hub repository.
You should see:
ai-olms
with the tag:
latest
So your final Docker Hub image is:
YOUR_USERNAME/ai-olms:latest
________________________________________
